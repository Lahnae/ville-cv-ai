AI-chat

Tämä AI-chat on osa omaa CV-sivustoani ja samalla käytännön esimerkki siitä, miten pilvipalveluita, serverless-arkkitehtuuria ja paikallista tekoälymallia voidaan yhdistää toimivaksi kokonaisuudeksi.

Chat käyttää Azure Static Web Apps -ympäristössä julkaistua Azure Functions -rajapintaa. Varsinainen tekoälymalli toimii omalla Windows-koneellani Ollaman avulla.

  • Frontend: HTML, CSS ja JavaScript
  • API: Azure Functions ja Node.js
  • AI: Ollama ja Qwen 2.5 7B
  • Oma malli: villebot
  • Yhteys: Tailscale Funnel
  • CI/CD: GitHub Actions
  • Hosting: Azure Static Web Apps

Tavoitteena on ollut rakentaa mahdollisimman kevyt ja kustannustehokas ratkaisu, jossa AI-inferenssi tapahtuu omalla laitteella ja verkkosivusto sekä API toimivat pilviympäristössä.
