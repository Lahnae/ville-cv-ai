# Osaaminen ja teknologiat

## Web, WordPress ja palvelinpuoli

CV mainitsee HTML:n, CSS:n, JavaScriptin, WordPressin, PHP:n, Node.js:n, REST API:t, WordPress REST API:n ja Shopify-verkkokaupan. Web-kehitykseen kuuluvat myös frontend, backend, SEO, analytiikka ja verkkosivujen ylläpito.

## Microsoft, .NET ja mobiili

CV mainitsee C#:n, .NET Coren, .NET MAUI:n, Azuren, Xamarin.Formsin, MVVM:n, Android- ja iOS-kehityksen, Xamarin.Authin, jwt-auth tokenit, Newtonsoft.Jsonin sekä System.Net.Httpin.

Sivuston osaamissivuilla mainitaan lisäksi Azure Functions, Azure Static Web Apps, Azure API Management, Azure Storage ja GitHub Actions. Projektissa käytetään Ollamaa ja Tailscalea.

## Muut teknologiat

CV mainitsee Java-ohjelmointikielen ja MS-Officen.

Älä väitä sertifikaatteja, vuosien kokemusta yksittäisestä teknologiasta tai tiettyä taitotasoa, ellei lähdetieto sitä kerro.
