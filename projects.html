Valittu projekti

AI-CV-chatbot

Käytännön esimerkki siitä, miten web-käyttöliittymä, serverless-rajapinta, pilvipalvelu ja paikallinen kielimalli voidaan yhdistää.

Tavoite

CV:hen voi tutustua keskustellen

Chatbot on osa omaa CV-sivustoa. Vierailija voi kysyä Villen työkokemuksesta, koulutuksesta, projekteista tai teknologioista. Vastaukset tuotetaan projektikohtaisella villebot-mallilla, joka toimii Ollaman kautta omalla Windows-koneella.

Arkkitehtuuri

Pyyntö kulkee selaimesta paikalliseen malliin

  1. SelainChatin käyttöliittymä lähettää viestin Azure Static Web Appsin /api/chat-rajapintaan.
  2. Azure FunctionsServerless-funktio välittää pyynnön ympäristömuuttujista saatavalla avaimella suojatulle proxy-palvelulle.
  3. Tailscale FunnelHTTPS-yhteys välittää pyynnön omalla Windows-koneella käynnissä olevalle palvelulle.
  4. Ollama & villebotPaikallinen Ollama tuottaa vastauksen; se palautuu samaa reittiä takaisin selaimeen.

Ollamaa ei julkaista suoraan internetiin. API-avain säilytetään Azure Static Web Appsin asetuksissa, ei käyttöliittymässä.
